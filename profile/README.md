# Aevion.ai

**Cryptographic verification infrastructure for AI systems.**

We build trust infrastructure that makes AI outputs verifiable, transparent, and auditable.

## What We Do

Aevion provides cryptographic proof systems for AI verification:

- **Ed25519 Signatures** - Industry-standard digital signatures
- - **SHA-256 Hashing** - Content integrity verification
  - - **XGML Support** - Human-readable proof format
    - - **Real-time Verification** - Sub-5ms latency
