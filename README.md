# Aevion — Proof-Native AI Governance

**Every AI decision. Receipted. Every claim. Bounded. No sorry, no slop.**

Aevion builds the infrastructure that converts AI-generated outputs into deterministic evidence receipts before human review. Our kernel includes a formally verified capability lattice (Lean 4), a five-gate evaluation pipeline (COE, MCP, x402, Exec, Patch), Byzantine fault-tolerant consensus, and hardware attestation.
